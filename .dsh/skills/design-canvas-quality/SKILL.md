# Проверки Design Canvas

`npm test` — контракт в Node; `smoke-gui.mjs` — единственное доказательство, что панель работает.
Ни то, ни другое не заменяет наблюдение за тем, что видит человек.

## Что запускать

| Команда | Что проверяет | Когда обязательна |
|---|---|---|
| `npm run check` | синтаксис всех `.js`/`.mjs` (`node --check`) | всегда, первым |
| `npm test` | ядро + инструменты и маршрут + контракт клиента | всегда |
| `DSH_WEB_TOKEN=… node smoke-gui.mjs <url> .gui-shot.png` | панель в живом DSH | при правке `client.js` |
| `npm run demo` | пересборка демо-фикстуры `demo/` | если изменилась модель документа или экспорт |
| `npm run preview` | превью `demo/preview*.png` для README из готового экспорта | если изменился демо-холст или экспорт |

`npm test` = `node smoke.mjs && node smoke-tools.mjs && node smoke-client.mjs`.

## Что покрывает каждый набор

| Файл | Покрытие |
|---|---|
| `smoke.mjs` | схема и нормализация (старый документ не обрастает новыми полями), токены (вложенные переопределения, `set-tokens` с `replace`+`remove`, отказ на опустевшем наборе), хранилище (реестр, `.design/`, ревизии, корзина, `project.json`), батч из 10 операций, транзакционность (ошибка в середине → `opIndex`, полный откат), компонент + инстансы + override + неймспейс id, защита корня от `define-component`, `ungroup` инстанса, `add`/`move` в не-контейнер, `clip` фрейма по умолчанию, `autoW`/`autoH` через нормализацию и запись, `set-canvas` с неизвестным устройством, валидация (дубли id, битый инстанс, пропавший токен), экспорт (`doctype`, `data-node`, `var(--color-accent)`, `:root`, поток доски и flex в `clean`, три файла, единицы, отсутствие `;;`), оптимистическая блокировка → 409, защита путей корзины (`..`, `.`, `../../etc`, `a/b`), раскладка (распределение свободного места `justify`, `align: 'stretch'`, авторазмер без лишнего промежутка), проект с `.design/` без записи в реестре (адресация по id после обнаружения), запись холста больше 8 МБ → 413 без порчи файла, `align` с противоречием `axis` и `mode` → 400, `add` с занятым id, контраст (порог по размеру текста, `rgb()`/`rgba()` с наложением на фон, авторские дети инстанса → `instance-children`), `autoW`/`autoH` по поперечной оси, неизвестная ось `distribute` → 400, параллельная запись одного холста без сырых ошибок |
| `smoke-tools.mjs` | регистрация ровно 9 инструментов с точными именами и формой (`execute`, `description`, `parameters`, `output.render`), потокобезопасность по факту записи, сквозной цикл агента (init → create → apply → 409 → read → components → tokens → validate → export), HTTP-маршрут (`GET /projects`, `/canvas`, `/display`, `/export`; `POST /apply`, `/canvas` с 409 и 400, `/tokens` с `replace`+`remove` и с опустошением, `/components`, корзина delete → list → restore; неизвестная операция → 400, несуществующий холст → 404), регистрация и снятие маршрута через `ctx.inject` (шпион `register` + disposer) |
| `smoke-client.mjs` | статический контракт `client.js`: нет `import`/`export`, загрузчик с id пакета, `require('react')`, отсутствие JSX, слоты и словари, `data-plugin`, токены `--dsw-alias-`, отсутствие хардкод-цветов, ≥12 `api('…')` по известным маршрутам, ≥6 POST, словари RU/EN, обязательные секции UI, отсутствие TODO, вид (pan/zoom) применяется к `.dc-world`, диалог экспорта не подменяется модалкой инициализации, паритет раскладки с `schema.js` **поведенческий**: функции `layoutFrame`/`normalizeLayout` вырезаются из исходника и прогоняются в Node по матрице случаев (значения и арифметика) |

## Живой прогон панели

```bash
DSH_WEB_TOKEN=<токен из адресной строки> node smoke-gui.mjs http://127.0.0.1:3080 .gui-shot.png
```

- Нужен запущенный DSH и открытая панель, иначе шаги упадут на отсутствии узлов.
- Сценарий опирается на **данные демо-проекта** (`demo`, холст `quiz-home`, узлы «История»,
  компонент `topic-card`, токен `color.bg`) и на **русскую локаль** хоста (ищет текст «ревизия»).
  Пересобирается фикстура командой `npm run demo`.
- Скрипт сам делает внешнюю правку через `POST /apply`, чтобы получить честный конфликт ревизий.
- Сообщения `409 (Conflict)` в консоли не считаются провалом — это рабочий протокол.
- Скриншот пишется в конце; при падении шага он не появится. Playwright берётся из установки или
  из кеша `npx`.
- Если прогнать нельзя (нет токена, нет DSH, нет браузера) — так и напиши в отчёте: непрогнанное
  не считается пройденным.

## Как добавить проверку

Стиль существующих наборов: чистый ESM, `node:assert/strict`, свой временный каталог, изолированный
`DSH_HOME` (иначе тест полезет в реальный реестр), уборка за собой, человекочитаемые сообщения
ассертов, финальный счётчик успешных проверок.

1. Ядро → `smoke.mjs`: создай проект во временном каталоге, примени батч, проверь документ и файлы.
2. Инструмент или маршрут → `smoke-tools.mjs`: фальшивый `ctx` с `tools.register` и поддельные
   `req`/`res` для маршрута.
3. Контракт клиента → `smoke-client.mjs`: статические проверки по тексту `client.js`. Добавляешь
   новый маршрут в `client.js` — сначала добавь его в известный набор в тесте.
4. Поведение панели → `smoke-gui.mjs`: новый шаг сценария и ассерт по DOM/тексту; не полагайся на
   тайминги сильнее уже имеющихся пауз.

## Чеклист приёмки

1. `npm run check` и `npm test` — зелёные, без пропущенных шагов.
2. Правка `client.js` → живой прогон панели; в отчёте: что наблюдалось, а не что «должно».
3. Новая возможность покрыта проверкой; исключение обосновано в отчёте.
4. Инварианты из `AGENTS.md` не нарушены — назови их явно.
5. README/`docs/ARCHITECTURE.md` синхронизированы; найденное, но не исправленное, добавлено в
   `docs/BACKLOG.md`.
6. Непроверенное перечислено отдельным пунктом.

## Расхождения README ↔ код

Известные несоответствия документации и реализации собираются в `docs/BACKLOG.md` — сверься с ним,
прежде чем объявлять находку новой. Открытые сейчас: семантика `add` с занятым id (подстановка или
ошибка — решение владельца), неполные `output.schema` инструментов, сохранение документа из панели
в обход структурных проверок сервера, непроверенная подхватка `client.js` без `dev:web`,
клавиатурная доступность панели и её поведение при узкой ширине. Уже закрытые и не требующие
повторного открытия: `autoW`/`autoH`, `rev` в модели документа, `after` у `move`, индексные
`target`, `axis` у `align` (валидируется), отсутствующие превью, `style.clip`, неработающие
`justify` / `align: 'stretch'`, pan/zoom, лишняя модалка при экспорте, поток верхних фреймов, лимит
размера при записи, адресация проекта, найденного по каталогу, порог контраста и `rgba()`, авторские
дети инстанса, ложный 409 автосохранения, читаемость предупреждающего цвета.
