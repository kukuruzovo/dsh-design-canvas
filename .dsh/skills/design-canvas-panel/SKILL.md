# Панель «Макеты» (client.js)

Файл — браузерный бандл (~6500 строк), React без JSX. Инварианты клиента — в `AGENTS.md`.
Здесь — контракт, устройство и ловушки. Механика слотов DSH — глобальный скил `cordis-plugin-development`.

## Контракт, который нельзя ломать

- Нет `import`/`export`; React — `require('react')`, разметка — `h(...)` (`h = React.createElement`).
- Экспорт через `window.__ModuleLoader__.load({ id: '@local/dsh-design-canvas', factory })`;
  `id` равен имени npm-пакета.
- Фабрика возвращает `{ name, inject: ['slots', 'locale'], apply }`.
- `<style>` вставляется с `data-plugin` и `data-plugin-css` — без них module-system отберёт стиль
  у следующего плагина и удалит его при выгрузке.
- Регистрация только через `ctx.slots.inject(name, cb)`: прямой `register` в недекларированный слот
  бросает, а вклад снимается при коллапсе декларации слота.
- Панель и иконка делят один `PANEL_ID = 'design-canvas'`: `main` (keyed, `key: PANEL_ID`) и
  `sidebar.panellist` (`id: PANEL_ID`, `order`, `label: () => t('panel')`). Разойдутся — клик по
  иконке упадёт на `layout.selectPanel: main panel … is not registered`.
- `PanelIcon` возвращает **голый `<svg>`**: кнопку и accessible-name рисует сайдбар из метаданных.
- Новый маршрут сначала появляется в `route.js`, потом в `client.js` — `smoke-client.mjs` падает
  на неизвестном `api('…')`.
- Тот же файл грузит автономное окно: `standalone/shell.js` ставит шим `__ModuleLoader__` и контекст
  с сервисами `slots`/`locale`. Шим реализует ровно те вызовы, которые делает панель; новый сервис
  контекста (`ctx.…`) — правка и панели, и шима, иначе окно без харнесса упадёт на старте
  (проверка — `npm run test:editor`).

## Состояние

| Что | Как хранится |
|---|---|
| документ | `doc` (state) + `docRef` — правки через `editDoc`, который клонирует, мутирует, кладёт снимок в историю |
| ревизия | `rev` (state) + `revRef` — синхронизируются в `openCanvas`/`save`/`applyTokens`/`runComponentAction` |
| история | `pastRef`/`futureRef`, лимит 60; `historyDepth` — только для доступности кнопок |
| развёрнутое дерево | `display` = локальная развёртка `doc` (панель правит документ до сохранения); `serverDisplay` — фолбэк |
| выбор проекта/холста | `localStorage` (`dsh.design.project`, `dsh.design.canvas`) через безопасные обёртки |

`docRef` нужен потому, что обработчики жестов и `save()` читают актуальный документ вне замыкания
рендера. `editDoc(..., { history: false })` — один снимок на жест (геометрия, переименование).

## Сервер

Транспорт один: `api(path, options)` → `fetch` с `cache: 'no-store'`; ошибка несёт `status` и `body`
(сетевой сбой → `status: 0`).

| Путь | Зачем |
|---|---|
| `GET /projects?canvases=1`, `GET /canvases` | реестр и холсты проекта |
| `GET /display` | открыть холст: `doc`, `display`, `tokens`, `components`, `stats`, `rev` |
| `POST /canvas` | сохранить документ целиком с `expectRev` |
| `POST /components`, `POST /tokens` | действия библиотеки и редактора токенов |
| `POST /create`, `POST /delete`, `GET /trash`, `POST /restore`, `POST /init` | холсты и корзина |
| `GET /validate`, `POST /export` | проверка и экспорт |

- **Автосохранение**: `useEffect` с дебаунсом 700 мс на `doc`; пока `conflict` не разрешён,
  автосохранение **остановлено** — иначе панель молча затрёт чужую версию.
- **409**: `save` кладёт тело в `conflict` и показывает баннер с двумя путями — «Взять версию с диска»
  (`reloadCanvas`) и «Перезаписать моей» (`save(true)` → `force: true`).
- **Перед `POST /components` и `POST /tokens`** панель досохраняет локальные правки, иначе ответ
  сервера перезапишет документ и несохранённое потеряется.
- Панель **не** использует `POST /apply` и GET-проекции — они для агента.

## Редактор

- Инструменты: `select` (V), `frame` (F), `rect` (R), `ellipse` (O), `text` (T); после создания
  инструмент сбрасывается в `select`. `line` и `image` из тулбара недоступны — только от агента.
- Pan/zoom: `view = {x, y, zoom}`; pan — средняя кнопка, пробел или ЛКМ по пустому месту при
  `select`; колесо — прокрутка, `Ctrl/Cmd + колесо` — зум к курсору (0.05…8). `canvasPoint`
  переводит координаты события в координаты холста; размеры оверлеев делятся на `zoom`.
  Вид применяется к `.dc-world` через `transform: translate(...) scale(...)` — держи преобразование
  и математику `canvasPoint` парой, иначе клик и создание узла разъедутся с курсором.
- Выделение: `selection: string[]`. Аддитивен `Shift+клик` и `Ctrl/Cmd+клик` — на холсте и в дереве
  слоёв; снятие узла отложено до отпускания без движения (`toggleId`), иначе `Shift`-протяжка
  не начиналась бы; у `locked` узла жест не стартует, поэтому там снятие сразу. `Ctrl+A` выделяет
  всё в области (`enteredId` или верхние фреймы), а исчезнувший «вошедший» контейнер сбрасывается
  эффектом на `doc`. Рамка выделения: по пустому месту и по фону контейнера (`scope`), клик по тому
  же фону выделяет сам контейнер (`clickId`). Дети инстанса не выделяются: клик по
  `<instanceId>/<childId>` сводится `baseId` к самому инстансу.
- **Жест пишет локальные координаты.** `x`/`y` узла — координаты родителя, а `absRect`/`flattenRects`
  дают абсолютные; в узлы идёт `startLocal` + сдвиг (`movableRoots` убирает потомков выделенных
  предков), абсолютные — только габариту (`startBox`) и привязке. Ресайз переводит результат через
  `localBox(box, drag.offset)`. Нарушение — «улёт» вложенного узла на смещение контейнера.
- Привязка при перемещении ограничена осями с ненулевым сдвигом (`allowed`): иначе на старте жеста
  объект уводит в сторону. `Shift` в движении — `axisLock` (строго по одной оси) и шаг 1px вместо
  10px; `Alt` отключает привязку целиком. У родителя с `layout.mode !== 'none'` координаты детей
  считает `layoutFrame`, поэтому жест движения там не оставляет следа — это известный долг
  (`docs/BACKLOG.md`), а не регрессия.
- Ресайз: 8 ручек у **последнего** выделенного; `Shift` на боковой — шаг 10, на угловой — пропорции;
  `Alt` — без снапа.
- Undo/redo: снимки документа; `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`; `Ctrl+Y` не поддержан.
- Прочие клавиши: `Ctrl/Cmd+S` — сохранить, `Escape` — сбросить инструмент и выделение,
  `Delete`/`Backspace` — удалить, `Ctrl+G` / `Ctrl+Shift+G` — группа и разгруппировка,
  `Ctrl+Alt+G` — «объединить в фрейм» (`groupSelection(ids, 'frame')`); при зажатом Ctrl/Cmd буквы
  инструментов не срабатывают.
- Отрисовка: вложенные absolute-дивы; `layoutFrame` раскладывает фреймы с `layout.mode !== 'none'`
  (позиции из порядка, `gap`, `padding`, `align`, авторазмер), `relayoutDoc` идёт снизу вверх.

## Темы и локализация

- Только переменные `--dsw-alias-*` (16 штук). Своей темы нет: панель следует теме хоста,
  переключение светлой/тёмной перекрашивает её автоматически.
- **Цветовой литерал `#rrggbb` обязан быть строкой в JS**, а не внутри шаблона `CSS` — иначе падает
  `smoke-client.mjs`. Исключения уже есть: `#000000`, `#8a94a6`, `rgba(0,0,0,0.45)`.
- Локализация: `ctx.locale.register(NS, { ru, en, zh: en })` внутри `ctx.effect`; язык выбирает хост;
  словарь `RU` — основной (~200 ключей), `EN` — фолбэк. Оба словаря обязательны.

## Ловушки, проверенные по коду

- **Модалки разведены списком `DIALOG_KINDS = ['canvas', 'component', 'init']`**: `DialogHost` рисует
  только их, диалоги экспорта и удаления узла — свои компоненты панели. Новый вид диалога добавляй
  в список, иначе он молча не отрисуется.
- `.dc-node-selected` навешивается, но правила в CSS нет — рамку рисуют оверлеи `.dc-sel`;
  на этот класс опирается `smoke-gui.mjs` как на маркер DOM.
- `layout.justify` (`start`/`center`/`end`/`space-between`) распределяет свободное место по главной
  оси, `align: 'stretch'` растягивает детей по поперечной. Свободное место есть только у фрейма с
  авторским размером по этой оси, поэтому при `justify !== 'start'` `layoutFrame` сохраняет размер,
  а не подгоняет его по содержимому. Арифметика обязана совпадать с `layoutChildren` из `schema.js`
  — паритет значений проверяет `smoke-client.mjs`.
- `expandTree` режет глубину на 32, обход дерева (`walkTree`) защищён `Set` от циклов — сохраняй
  обе защиты.
- Форма узла (`makeNode`) и правила разворачивания инстанса обязаны совпадать с серверными
  (`schema.js`), иначе документ «поедет» после первого сохранения.
- **Сохранять документ можно только по одному запросу.** `save` держит флаг «в полёте»: второй
  вызов с той же `expectRev` вернул бы 409 и панель показала бы конфликт собственного
  автосохранения. Пропущенный вызов повторяется после ответа, если документ успел измениться.
- **`--dsw-alias-state-warn-primary` — не цвет текста на светлом фоне**: `#f59e0b` на белом даёт
  2.15:1 при норме 4.5:1 для 10.5–12px. Для предупреждающего текста цвет смешивается с «чернилами»
  темы (`color-mix(in srgb, … 62%, var(--dsw-alias-label-primary))`), для рамок и маркеров годится
  сам токен.
- **`--dsw-alias-brand-primary` — «чернила», а не акцент**: в обеих темах он равен цвету основного
  текста, поэтому заливка под светлым текстом им не рисуется.
- `select` — единственный элемент, у которого не было фокуса вовсе (`outline:none` без правил);
  `:focus-visible` обязателен. У дерева слоёв, панели замечаний и вкладок фокуса и `tabIndex` нет —
  это известный долг, см. `docs/BACKLOG.md`.

## Чеклист перед правкой `client.js`

1. Нет JSX, `import`, `export`; разметка через `h(...)`.
2. Не тронуты `data-plugin`/`data-plugin-css`, `id` загрузчика, `PANEL_ID`, обёртки `ctx.slots.inject`,
   `locale: NS` в обеих регистрациях.
3. Новые цвета — токенами темы либо JS-строкой, но не в шаблоне `CSS`.
4. Новый маршрут сначала добавлен в `route.js`.
5. Прогнаны `npm test` **и** живой прогон панели (`smoke-gui.mjs`) — статический контракт не
   доказывает, что панель работает.
